How visitor tracking works

1

The public page calls POST /api/visitors/track once on load. nginx serves the HTML directly, so the backend never sees the page request itself.

2

The visit is recorded against the address taken from X-Forwarded-For, falling back to the direct peer address.

3

Total visits count every hit; unique visitors count each address only once per day, so a reload never inflates the number.
